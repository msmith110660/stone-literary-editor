Getting Started

What this app does

Paste your manuscript or document and the app scans it for errors. Each flagged issue is highlighted so you can review it and decide whether to fix it or keep it as intentional author voice.

Getting an API Key

  1. Go to console.anthropic.com
  2. Create a free account or sign in
  3. Navigate to API Keys and click Create Key
  4. Copy the key — it starts with sk-ant-

Your key is saved automatically after first use.

Genre

  • Fiction — respects fragments, dialect, and stylistic voice
  • Non-fiction — respects author voice, flags mechanical errors
  • Academic — strict grammar and punctuation standards
  • Business — professional writing conventions

Pass Type

  • Errors Only — spelling, grammar, punctuation only
  • Full Pass — also flags clarity, word choice, and style

Ignore List

Add character names, invented words, or any terms you don't want flagged. Separate entries with commas.

Usage

  1. Set your genre and pass type
  2. Paste your text and click Analyze Text
  3. Use Next / Prev to step through each flagged issue
  4. Fix it in your document or skip if it's intentional
  5. Click New to start a fresh session

API costs

Each analysis costs roughly $0.01–$0.03 per 10,000 words, billed directly to your Anthropic account.
